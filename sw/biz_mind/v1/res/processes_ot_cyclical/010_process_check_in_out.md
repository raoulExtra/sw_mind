# Check-in / Check-out Procedure

## Overview

Standardized procedure for documenting tenant arrival and departure at rental properties.

## Check-in Process

### Pre-Arrival
- [ ] Confirm move-in date with tenant
- [ ] Schedule inspection time
- [ ] Prepare property for inspection

### Move-in Inspection
- [ ] Document meter readings (electricity, water, gas)
- [ ] Photograph property condition (all rooms, walls, floors, windows)
- [ ] Verify inventory check-in (furniture, appliances, fixtures)
- [ ] Sign move-in checklist with tenant
- [ ] Provide tenant with property manual and contact information

### Post-Check-in
- [ ] Enter data into property management system
- [ ] Set up utility accounts
- [ ] Schedule regular inspections

## Check-out Process

### Pre-Check-out
- [ ] Schedule final inspection date
- [ ] Review lease terms and conditions
- [ ] Notify utility providers of termination dates

### Move-out Inspection
- [ ] Document final meter readings
- [ ] Photograph property condition
- [ ] Compare with move-in documentation
- [ ] Identify any damages or missing items
- [ ] Complete move-out checklist
- [ ] Schedule key return

### Post-Check-out
- [ ] Process security deposit return or deductions
- [ ] Transfer utilities to landlord
- [ ] Update property management system
- [ ] Prepare property for next tenant

## Required Documentation

- Move-in / Move-out checklists
- Meter reading logs
- Property condition photos
- Inventory lists
- Utility bills
