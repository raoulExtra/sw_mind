# The Relic Way - Core Values

New Relic's six core values that guide collaboration, diversity, decision-making, and goal achievement:

## 1. Results Driven
**Own the outcome, not just the task.**

## 2. Customer Forever
**Place customers at the center of everything.**

## 3. One Team
**Use diverse perspectives to find the best way forward.**

## 4. Competitive Spirit
**Shape the market—don't just respond to it.**

## 5. Technical Excellence
**First set the standard, then exceed it.**

## 6. Challenger Mindset
**Focus on "how might we?" instead of "why we can't."**
