# Core Development Roles

Roles for software development teams:

| Role | Level | Description |
|------|-------|-------------|
| Developer | l1 | Designs, codes, and tests software components |
| Product Manager | l2 | Defines product vision, manages backlog |
| Designer | l1 | Creates user interfaces and ensures intuitive UX |
| QA Engineer | l1 | Ensures software quality through testing |
| DevOps Engineer | l2 | Automates deployment and manages infrastructure |
| Software Architect | l3 | Designs system structure and sets technical standards |
| Engineering Manager | l3 | Manages engineering team and ensures delivery |
| Project Manager | l2 | Coordinates schedules and removes blockers |
